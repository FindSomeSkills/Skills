# 竞品版式拆解：值得借鉴的已验证做法

采样时间：2026-11-13
方法：无头浏览器 1280×900 截图 → 逐像素统计主色与留白比例 + 人工读版式。
脚本：`tools/analyse-competitors.mjs`（可复跑）

## 一、四个样本的硬数据

| 站点 | 平均亮度 | 近白像素 | 主色 | 定位 |
| --- | --- | --- | --- | --- |
| iLovePDF | 241 | 85% | 白 + 红（仅 CTA） | 在线工具集合，全球流量前列 |
| it-tools | 237 | 86% | 白 + 绿（品牌） | 开发者工具箱，开源 |
| TinyPNG | 161 | 46% | 白 + 深灰 + 绿 | 单一功能极致 |
| JSONFormatter | 207 | 57% | 白 + 绿 + 灰 | 单一工具 + 广告 |

**共同点**：全部白底。没有一个是深色默认。品牌色只出现在一处（CTA 或 Logo），其余全灰。

## 二、iLovePDF 的版式结构（最值得参考的一个）

```
白底页头：Logo │ 工具名横向导航（Merge / Split / Compress / Convert…）│ Login │ 红色 Sign up │ 九宫格图标
   ↓
Hero：44px 标题「Every tool you need to work with PDFs in one place」
      一行副标题，说明免费、几秒完成，不提功能清单
      背景极淡渐变（近白，看不出明显颜色）
   ↓
筛选胶囊行：All（深色实心）│ Workflows │ Organize PDF │ Optimize PDF │ …（白底描边）
   ↓
工具网格：4 列 × N 行
      每张卡：48px 彩色图标 + 20px 粗体名称 + 2 行灰色说明
      白卡、16px 圆角、细边框、极轻阴影
```

三个关键决策：

1. **一行放 4 张卡**，1280 宽下信息密度最高，用户一屏看到 8 个工具
2. **图标是唯一的彩色元素**，卡片本身全白，扫视时靠图标定位而不是靠颜色
3. **红色只出现在 Sign up**，其余全部中性色——重点集中在唯一的主操作上

## 三、it-tools 的结构（开发者工具箱的标杆）

```
左侧栏：按分类列出所有工具（Crypto / Converter / Web…），带小图标
顶栏：搜索框（Ctrl+K）│ 语言 │ GitHub │ X │ 深色开关 │ Buy me a coffee
主区：4 列卡片网格，每卡 = 图标 + 名称 + 2 行截断描述 + 收藏心形
```

两个值得抄的：

1. **搜索框放最显眼位置（Ctrl+K）**，工具多了以后比导航好用
2. **卡片描述强制截断成 2 行**，保证所有卡等高，网格整齐

## 四、我们现在的差距

| 维度 | 竞品 | 我们 | 差距 |
| --- | --- | --- | --- |
| 列数 | 4 列 | 3 列 | 一屏少 2 个工具 |
| 图标 | 每个工具有图标 | 文字标题开头 | 扫视速度慢 |
| 卡片描述 | 1 句，2 行截断 | 3 句（"你会得到…"+补充） | 文字过重，卡片过高 |
| 强调色 | 只在 CTA | 卡片标题、链接、按钮全是蓝 | 重点被稀释 |
| 搜索 | 有（it-tools） | 无 | 6 个工具时可以不要，10 个以上必须有 |
| 分类 | 胶囊筛选（iLovePDF） | 无 | 同上 |
| 社会证明 | "GitHub 加星"块 | 无 | 弱 |

## 五、借这些，不借那些

### 建议照做（投入小、已验证）

1. **网格改 4 列**（≥1100px 时），移动端仍 1 列
2. **每张卡加一个 40–48px 的线性图标**，单色（不用彩色），颜色跟随强调色
3. **卡片描述压到一句**，最多两行，超出省略。删掉"你会得到："这种前缀
4. **强调色收敛**：蓝色只给主 CTA（首页入口条、检查按钮）与当前选中项；卡片标题、普通链接改回前景色
5. **卡片等高**：描述固定两行高度，按钮贴底

### 建议加（为工具变多做准备）

6. **搜索框**：工具超过 10 个再加，现在加会显得空
7. **分类胶囊**：等有 10 个以上再分「同步 / 检查 / 分析」
8. **侧边栏导航**：工具超过 15 个再考虑

### 不建议借

- **iLovePDF 的彩色图标**：他们有设计师维护几十个图标，我们手画会显得脏；单色线性图标够用
- **JSONFormatter 的广告位**：那是变现选择，不是设计优点
- **TinyPNG 的单功能极简**：我们是工具箱，需要网格而不是单一大输入框
- **it-tools 的"Buy me a coffee"**：现阶段没有收款渠道，等有流量再说

## 六、一句话结论

四个高流量站共同的规律不是"某种风格"，而是：**白底、少色、一屏塞下尽量多工具、每个工具一句话说清**。我们现在最缺的是第 3 条——卡片里的三句话（"你会得到…"）对老用户是噪音，对新用户也不如一句具体成果有用。
