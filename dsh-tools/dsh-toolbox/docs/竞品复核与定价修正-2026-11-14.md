# dsh-plugin.org 竞品复核与定价修正

**结论：目前不能确认 DSH Toolbox 的普通安装或诊断服务能卖到 $49–99，也没有证据支持换成另一个固定价格。撤回把 $49–99 人工服务作为默认起步方案，以及 $9–19/月作为自然产品化方向的建议。** 旧报告虽将其标为测试假设，但在缺少具体竞品比较、交付能力和付费证据时就推进服务页，执行顺序仍然过早。

这次修正依据是新检索到的免费替代能力，而不是用户质疑本身。免费替代的存在削弱通用功能的收费理由，但不能单凭它证明所有个性化服务都卖不出去。

## 当前可保留的定位假设

网站可继续作为免费、浏览器内、本地文件检查与问题解释入口。对不愿安装插件、DSH 本身无法启动、只想离线检查副本的人，浏览器式工具可能有便利性；**这是待验证的使用价值，不是已证明的付费差异**。

同步方案也不能直接视为等价：dsh-sync README 的默认配置为 `workspaceState: false`，并警告多机直接共享 workspace.json 会互相覆盖；本站 Sync Hub 声称处理工作区索引同步。可以用同一份双机合成样例验证“会话文件到达后，列表/标题是否正确且无覆盖”，再判断真实差异。仅凭 README 不能证明本站方案优于它，更不能推出售价。

最多选择一个残余问题继续验证，例如“免费方案仍不能解释某次迁移后的会话索引不一致”。先比较现有免费方案，再证明本站在哪个具体版本/输入上提供额外结果。如果没有剩余差异，应推荐已有免费工具，不再重复开发。

本轮不建议把站点全部推翻，也不建议全改收费或改成低价商城。技术审计中已证实的标题、日期、事实表述、输入渲染和隐私问题仍值得修；它们与价格能否成立是两回事。

## 收费证据与决策顺序

1. 记录目标用户实际遇到的问题、尝试过的免费方案、未解决部分和真实影响；不能只问“你愿不愿意支持我们”。先争取 10 次合格对话，数量是研究目标，不是已取得成果。
2. 对确实需要协助的人，提供一个能交付、有范围和验收条件的方案，按问题单独报价。记录真实报价、接受或拒绝原因；不先把 $49–99、$9.9 或 $19.9 写成市场价格。
3. 第一笔真实独立客户付款仅验证这一位客户和这一项交付。记录费用、退款和实际工时；重复得到正向结果，才支持做套餐或产品化。
4. 如获得 3 个完成交付且非人情支持的付费案例，并出现相似需求，可尝试标准化服务；订阅另需证明重复使用、持续价值和续费意愿。
5. 如果用户用免费工具就能解决，或者报价低于可持续交付成本，保留免费获客资产并停止该付费方向。广告、赞助或联盟也没有流量/合作证据，不能自动成为替代的收入保证。

**首美元时间、月收入与收入上限仍无法可靠估计。** 未来 14–30 天可作为需求研究和试单观察周期，不再表述为有依据的首单时间预测。旧报告的数字模型仅保留为算术例子，不作为当前经营预测或开发依据。
